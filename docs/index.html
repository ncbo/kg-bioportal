Browse the graphs

Open the KG-Bioportal graph browser → — a BioPortal-style interface listing both the BioPortal ontologies transformed to KGX (downloadable here) and external knowledge-graph projects registered in KG-Registry. Because the transformed ontologies are themselves KGX graphs, they live in the same browser; each entry is tagged by source and shows node/edge counts, version, and a download link.
